¿Qué son las Ciencias Forenses?

Las Ciencias Forenses utilizan conocimientos científicos para analizar evidencias que ayudan a esclarecer hechos relacionados con una investigación.

Estas ciencias apoyan a las autoridades mediante el estudio de muestras, objetos y otros elementos importantes para la justicia.

Áreas de las Ciencias Forenses

Medicina forense

Estudia lesiones y otras condiciones médicas que pueden ser importantes en una investigación.

Genética forense

Analiza muestras biológicas, como el ADN, para ayudar a identificar personas.

Toxicología forense

Estudia sustancias que pueden ser relevantes para una investigación.

Importancia de las Ciencias Forenses

Las Ciencias Forenses permiten analizar evidencias mediante métodos científicos. Sus resultados pueden contribuir a las investigaciones y apoyar a las autoridades.
